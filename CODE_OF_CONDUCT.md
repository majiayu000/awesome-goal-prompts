# Code Of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Standards

Contributors should keep discussion specific, respectful, and evidence-based. This is especially important for source-backed examples: do not attribute prompts, claims, or product behavior to a person or tool unless the linked public source supports it.

## Enforcement

Maintainers may reject contributions that include harassment, personal attacks, spam, fabricated citations, copied private material, or unsafe engineering instructions.

Report problems through the repository issue tracker or maintainer contact listed on GitHub.
